A set is defined as a <u>collection of elements</u> where elements can be abstract or real. 
$$A=\{x \mid x \in E\}$$
Where $A$ is the identifying label of the set containing elements $x$ where $x$ is part of set of elements $E$ which cumulatively depicts all types of objects.  Any individual object $o$ cannot be considered as set.

<u>Cardinality</u> is the number of objects in a set. 

If all members of $A$ are present in $B$ and all members of $B$ are present in $A$ then we can say $A = B$.

If all members of $A$ are present in $B$ regardless of order and repetition, $A$ can be said to be a <u>subset</u> of set $B$ denoted as $$A \subseteq B$$
If $A \subseteq B$ and $B\subseteq A$ then we can say $A = B$. If $A \subseteq B$ but $A \ne B$ then $A$ is called a <u>proper subset</u>. 

The empty set is a set containing no elements. It is depicted by $\varnothing$.
